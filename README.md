# ai-engineering.space

Сайт AI Engineering — внедрение ИИ в бизнес с упором на безопасность решений.

Стек: [Next.js](https://nextjs.org) (шаблон [Blazity/next-saas-starter](https://github.com/Blazity/next-saas-starter)), static export, GitHub Pages.

## Локальная разработка

```bash
npm install
npm run dev
```

## Деплой

При пуше в `main` GitHub Actions собирает статический экспорт (`out/`) и деплоит на GitHub Pages.
